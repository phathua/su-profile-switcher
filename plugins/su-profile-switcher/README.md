# SketchUp Profile Switcher Plugin for Antigravity

Autonomous SketchUp workspace orchestration and extension profile switcher.

## Capabilities
- Inspect installed SketchUp versions and profiles.
- Safely switch between profiles (Plugins, Shortcuts, Toolbars, Materials, Templates).
- Protect critical rendering engines (V-Ray, Enscape, D5) from licensing disruption.
- Gracefully detect and manage SketchUp processes.

## Provided MCP Tools
- `sups_list_versions`
- `sups_list_profiles`
- `sups_get_current_profile`
- `sups_switch_profile`
- `sups_save_profile`
- `sups_inspect_profile`
- `sups_sketchup_status`
- `sups_sketchup_control`
